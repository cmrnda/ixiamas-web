# Sitio web Ixiamas 2024

Página multipágina basada en la Revista Sociocultural de Ixiamas 2024.

## Archivos principales
- index.html
- geografia.html
- historia.html
- cultura.html
- conservacion.html
- desarrollo.html
- fiesta.html
- galeria.html

## Cómo ver
Abrir `index.html` en el navegador.

## Nota
No se colocaron páginas escaneadas completas del PDF. Solo se usaron recortes de fotografías como apoyo visual.
