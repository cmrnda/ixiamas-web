Propuesta digital institucional

Esta página web fue desarrollada por estudiantes de la Universidad Mayor de San Andrés (UMSA), como parte de una propuesta digital orientada a fortalecer la presencia institucional del Gobierno Autónomo Municipal de Ixiamas.

Para soporte, mantenimiento o mejoras del sitio web, puede comunicarse con el equipo desarrollador.

web Sitio web estático

El proyecto está construido con HTML, CSS y JavaScript puro. No incluye backend, base de datos, panel administrativo ni sistema de usuarios.
